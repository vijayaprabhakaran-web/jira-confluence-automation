# Validation Rules

## Required structure for walkthrough files
Every walkthrough file in the modules directory must include the following sections:

- Summary
- Quiz

## Rules
1. Each walkthrough file must start with a top-level heading such as `# Walkthrough` or a descriptive title.
2. The file must contain a `## Summary` section.
3. The file must contain a `## Quiz` section.
4. The `Summary` section should briefly describe the key concepts, objective, and outcomes of the module.
5. The `Quiz` section should include at least one question and an answer key or answer block.
6. The content should be plain Markdown and readable in a standard repository viewer.
7. Do not leave either required section missing.
8. Use consistent heading capitalization: `Summary` and `Quiz`.

## Example

```markdown
# Walkthrough

## Summary
This walkthrough introduces the main concept and expected learning outcome.

## Quiz
### Question
What is the key idea of this module?

### Answer
The key idea is the core concept this module teaches.
```
